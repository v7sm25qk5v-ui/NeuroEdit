# NeuroEdit v0.5.17-alpha

This release includes the implemented NE-012–NE-031 ticket pass and Claude's
follow-up corrections, building on v0.5.16-alpha.

## Included updates

- **Project preservation:** keep unreadable autosaves intact, ask before
  replacing scratch cases (including notes-only projects), preserve managed
  assets, and retain undo history and preview after Save As.
- **Editing and review:** coalesce slider/text gestures into useful undo steps;
  preserve review through view-only actions; commit typed spinbox values before
  Save, Export, Undo, or Quit; invalidate review again when an inspector edit
  changes content after re-confirmation.
- **Export correctness and robustness:** paint overlays in source-frame space;
  decode still images consistently with EXIF orientation; publish across volumes
  atomically; validate bundled FFmpeg; improve frame padding, caption formatting,
  stderr handling, and export-report notices.
- **Caption review:** review speaker labels and literal transcript text, require
  caption PHI confirmation, and confirm sidecar exports.
- **Performance and responsiveness:** sequential decoding for render-path video
  export, cached playback file checks, and background audio duration probing with
  cancellation and stale-result handling. A synthetic 1080p long-GOP benchmark
  measured 6.258 s before versus 1.200 s after, with identical pre-encode frames;
  this is not a performance guarantee for real recordings.
- **Tutorial/SAM/lifecycle:** protect existing projects during tutorials, end the
  tour before project replacement, improve weight-cache detection/deletion and
  partial-mask cleanup, retain worker references through native thread cleanup,
  and route error notices to the GUI thread.
- **Release tooling:** shared quality workflow, pinned actions/tools, informational
  Windows testing, one numeric version source, separate artifact labels, and
  explicit GitHub Latest publication/verification.
- **Follow-up test cleanup:** delete temporary audio panels on the GUI thread;
  Claude reports this addressed the observed test-only intermittent native crash.

## Validation and limits

Claude's November 16 handoff records **696 passing tests on three consecutive
runs**, each with a clean exit, plus Ruff and diff checks. Per the owner's
instruction, local tests were not rerun for this publication. The normal release
workflow still gates packaging on hosted quality checks; final build and asset
verification is recorded in the project handoff.

Physical audio/microphone behavior, real SAM/GPU inference, native Windows
UI/scaling, installed-app smoke tests, and exports of real clinical recordings
were not verified in this publication work. Cancellation discards an audio-import
result but does not interrupt a probe already running. Known review follow-ups
are retained in HANDOFF.md; this release is not a claim of a complete security or
clinical audit.
