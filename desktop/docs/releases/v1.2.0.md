# NeuroEdit 1.2

- Import video and images at the playhead or drop them at a specific point on
  the timeline. Media snaps to the nearest clip boundary, later items shift to
  make room, and the playhead jumps to the first imported clip.
- Drag a clip to reorder it and its connected labels, markers, slides, captions,
  and audio move with it. Whole-timeline labels and narration spanning several
  items stay in place. Opening titles stay first when you drag a clip to the front.

Use **Help → Check for Updates…** to update an existing install, or download
an installer below. The optional SAM runtime is available in source builds.
