# NeuroEdit v0.5.18-alpha

This release adds import support for `.mpg` and `.mpeg` recordings through
managed MP4 working copies, while retaining the v0.5.17-alpha editor updates.

## Included updates

- **MPG/MPEG import:** convert MPEG program streams to H.264 MP4 in the project's
  `media/` folder before editing. The original file is not modified, and the clip
  retains its original name. This gives preview and frame-by-frame export the
  normal MP4 seeking behavior rather than editing the program stream directly.
- **Background conversion:** per-file progress, cancellation, readable failure
  reasons, atomic final names, and reuse of unchanged source files. Edited source
  files receive a new working copy.
- **Project portability:** Save As copies managed media, and opening a moved
  project reconnects its working copies in the new project's `media/` folder.
- **Managed cleanup:** discarded/failed imports remove new copies; close-time
  cleanup preserves user-owned media and copies referenced by the project,
  saved document, or undo history.

MPG/MPEG import uses extra project storage for the working copy. Other supported
video formats retain their existing import behavior.

## Validation and limits

Claude's November 17 handoff records **723 passing tests twice**, clean process
exits, 27 MPG-specific regression tests, and clean Ruff/diff checks. No local
tests were rerun for publication, per the owner's instruction. The normal hosted
CI gates remain in place; final build and download verification is recorded in
the project handoff after publication.

Real MPG footage from the user's equipment, installed-app behavior, and native
Windows interaction were not verified in this publication work. Conversion keeps
only the first audio stream; truncated input can produce a shorter copy. The UI's
existing "Keep in Place" wording does not describe the extra MPG working copy.
Save As can pause the UI while copying large working copies. Relinking directly
to an MPG is refused with an explanation; import it to create a working copy.
Other known limitations remain recorded in HANDOFF.md.
