# NeuroEdit 1.0

**Save As** uses one dialog to name the project and choose a writable location.
NeuroEdit remembers the last folder you used.

- When project media needs to move to the new location, copying runs in the
  background with a progress bar, file count, and Cancel button.
- A save checks for available disk space and asks before replacing an existing
  project. Files shared by the project and its undo history are copied once.

If you have an updater-enabled build, choose **Help → Check for Updates…**.
The installers below contain the editor. The optional SAM runtime is available
in source builds.
