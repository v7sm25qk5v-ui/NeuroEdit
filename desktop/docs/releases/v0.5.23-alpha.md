# NeuroEdit v0.5.23-alpha

Find moments faster with thumbnail filmstrips in the Video track. NeuroEdit
does less work while scrubbing, restoring a project, and closing the editor.

- Filmstrips sample from each clip’s trimmed source range and update as you zoom
  or scroll. Clip labels and trim handles stay visible. Thumbnails decode in
  the background and stay in memory. Clips sharing a source with a timeline
  redaction use plain bars.
- Scrubbing combines rapid pointer moves and seeks to the release position.
  Frame stepping uses the requested position even for small seeks.
- Projects with many clips split from one source probe that file once.
  Close cleanup reuses path checks, and SAM loads when you open its panel.

Unsigned editor-only alpha builds. Installed v0.5.19-alpha or later builds
can update through **Help → Check for Updates…** from a writable install.

In synthetic Mac tests, restoring 120 splits from one file took 152 ms,
down from 220 ms. Closing a project with 36 undo snapshots took 7 ms, down
from 56 ms. Seek speed still depends on the source and decoder. Native Windows
operation and playback with real project footage remain unverified.
