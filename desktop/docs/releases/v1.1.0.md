# NeuroEdit 1.1

- **Export Movie…** brings quality, captions, audio, destination, and privacy
  review into one dialog. It estimates output size and export time, remembers the
  last destination, and matches the video's frame rate by default.
- Exports run in the background. The Export button shows progress and estimated
  time remaining. Click it during export to cancel.
- NeuroEdit checks destination access and disk space before encoding. Finished
  exports offer a shortcut to the output file. Reports are saved in the project's
  `Export Reports` folder.

Use **Help → Check for Updates…** to update an existing install, or download
an installer below. The optional SAM runtime is available in source builds.
