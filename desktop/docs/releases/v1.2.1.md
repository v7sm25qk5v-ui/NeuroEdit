# NeuroEdit 1.2.1

- Timeline zoom, Fit, Snap, Mark, Split Clip and fade controls now share one
  full-width bar with playback, Take Still and playback speed.
- Reclaims unused space beneath the timeline. Removes the old 300-pixel track
  viewport cap so stacked labels and slides can use a taller timeline pane.
- Narrow windows keep playback visible and allow horizontal scrolling through
  editing controls. Resizing back to a wide window or removing stacked rows
  returns freed space to the preview without an empty area below the timeline.
- Keeps existing editing shortcuts and manually adjusted timeline pane sizes.
- Cancels queued timeline layout work when the editor closes.
- Includes the import-placement and connected-storyline changes from v1.2.0.

Use **Help → Check for Updates…** or download an installer below. Installers
are unsigned and not notarized; optional SAM/PyTorch remains source-build only.
