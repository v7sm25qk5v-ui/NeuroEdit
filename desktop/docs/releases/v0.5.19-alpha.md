# NeuroEdit v0.5.19-alpha

First alpha with the in-app updater, retaining the MPG/MPEG import and editor
improvements from v0.5.18-alpha.

## Try it

1. Install this release manually once: use the macOS DMG or Windows installer.
2. Open **Help → Check for Updates…**.
3. This release reports **up to date** while v0.5.19-alpha is GitHub Latest.
   When a newer release is published, the dialog offers its release notes,
   **Download**, and **Install and Restart**.

Older installed versions do not contain the updater and cannot update themselves
to this first updater-enabled build. No synthetic newer release is advertised.

## Included updates

- Check the fixed NeuroEdit GitHub Latest release on request; display full
  alpha-version tags and plain release notes. No startup network polling.
- Download with progress/cancel into private temporary storage. Expected size
  and SHA-256 must match before installation; retries ignore stale callbacks.
- Respect recording/background-job/save guards, flush pending typed edits, and
  reopen the same saved project after restart. Failed saves or helper launches
  leave the current editor running; existing clean files are not rewritten.
- macOS stages the ZIP, validates bundle/version and safe paths/symlinks, then
  uses a detached replacement/relaunch helper with rollback for swap/launch errors.
- Windows uses the existing install directory and explicit Inno restart flow
  after the editor exits. No force-kill or OS security-policy bypass.
- Source checkouts and read-only install locations provide manual-install guidance.
- Build metadata records full release tags, and the Windows fixture path
  normalization setup assertion is corrected.

No videos, audio, or project contents are sent to GitHub by update checks.

## Validation and limits

Before publication, the complete local suite passed **765 tests**, including
**42 updater tests**, with a clean exit and senior review. A real macOS bundle
built and its update ZIP staged with valid code signatures; a real GitHub/CDN
ZIP download passed hash/size verification without installation. Publication CI,
assets, and Latest verification are recorded in the project handoff.

Actual installed-app replacement/restart on macOS and native Windows installer
execution/restart remain alpha smoke tests for users. macOS rollback covers
failed replacement or rejected OS launch, not an app crash after launch succeeds.
Other existing real-media, audio, Windows UI, and SAM validation limits remain.
