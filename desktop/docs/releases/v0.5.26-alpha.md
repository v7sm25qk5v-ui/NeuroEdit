# NeuroEdit v0.5.26-alpha

- The light theme uses pale watercolor blues and the dark theme uses charcoal
  with muted blue accents. Buttons, fields, menus, and list rows have rounder corners.
- Number fields have themed up and down chevrons, and dropdowns use matching arrows.
- Scrolling over an unfocused number field, dropdown, or slider scrolls its
  panel without changing the control's value. Focus the control to adjust it
  with the scroll wheel.
