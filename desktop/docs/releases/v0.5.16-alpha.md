# NeuroEdit v0.5.16-alpha

This release refresh includes all implemented updates through November 15,
2026. It carries forward the v0.5.15-alpha timeline fixes and incorporates the
latest review, backlog, architecture, and handoff documentation. Remaining open
backlog tickets are not implemented by this release.

## Included updates

- **Redaction timing through timeline edits (NE-010):** conservative coverage
  rules preserve covered footage through ripple edits and reposition redactions
  with their footage during clip reordering. A finite redaction does not become
  an unlimited one through duration reduction.
- **Consistent trim dragging (NE-011):** both trim handles reapply edits from
  the timeline state captured at mouse press, keeping ripple results independent
  of the drag path. Snapping and drag-to-trash use that same starting state.
- **Current documentation:** includes the latest optimization findings and
  architecture notes; completed ticket statuses, installer links, and numeric
  package/app/bundle defaults are aligned to this release.
- **Existing editor workflow:** retains narration preview, recording placement
  and safe-close behavior, media relinking, background video import, explicit
  audio-probe failure, SAM cancellation, and isolated screenshot tooling from
  v0.5.14-alpha.

## Validation and known limits

Release validation and build/publication results are recorded in the
[project handoff](https://github.com/v7sm25qk5v-ui/NeuroEdit/blob/main/HANDOFF.md).
Quality checks must pass before installer publication.

Fresh local validation passed **381 tests** with no skips and a clean process
exit, plus Ruff, source compilation, version/default checks, and build-script
shell syntax. Native app preferences were unchanged by validation. The existing
v0.5.15-alpha tagged CI was independently confirmed to have passed 381 tests and
published all three installers before this refresh.

Redactions spanning clips that are reordered apart can widen to one conservative
time window. Rendered clinical footage, physical audio/microphone behavior,
native Windows UI/scaling, and actual SAM inference were not verified in this
release work. Other open issues remain in `CODING_TICKETS.md`; this release
does not claim to resolve the full backlog or complete a security audit.
